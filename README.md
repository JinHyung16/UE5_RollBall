# RollBall

공을 굴려 몰려오는 적을 피하며 스테이지를 계속 깨 나가는 인크리멘탈 게임입니다.

처음에는 한 번만 부딪혀도 쓰러질 만큼 약하지만, 판마다 모은 골드로 공을 조금씩 강하게 만들어 더 높은 스테이지로 올라갑니다.

## 조작

| 키 | 동작 |
|---|---|
| W A S D | 공 굴리기 |
| Space | 점프 |

## 게임 흐름

1. 스테이지에서 적을 피하며 제한 시간을 버팁니다.
2. 적을 쓰러뜨리거나 오래 버틸수록 골드를 얻습니다. 져도 모은 골드는 남습니다.
3. 골드로 스킬 트리를 찍어 공을 강하게 만듭니다.
4. 다시 도전해 더 높은 스테이지로 올라갑니다.

## 스테이지

- 모두 100 스테이지이고, 한 스테이지는 약 12분입니다.
- 끝까지 버티면 다음 스테이지로, 쓰러지면 같은 스테이지를 다시 합니다.
- 마지막 2분에는 강한 적이 나오고, 5 스테이지마다 보스가 나옵니다.
- 스테이지가 오를수록 적이 더 단단하고 빨라지며 더 자주 나옵니다.
- 발판과 바위 배치가 스테이지마다 달라집니다.

## 적

| 적 | 특징 |
|---|---|
| 빨간 원통 | 공을 쫓아오고, 닿으면 체력이 줄어듭니다 |
| 파란 공 | 굴러와 부딪히며 공을 밀쳐냅니다 |
| 초록 상자 | 제자리에서 길을 막습니다 |
| 운석 | 위에서 떨어집니다 |

## 스킬 트리

골드로 공을 강하게 만드는 곳입니다.

- 가운데 시작점에서 네 방향으로 스킬이 이어져 있습니다.
- 스킬 하나가 능력치 하나를 올립니다. 한 번에 끝나는 스킬도 있고, 여러 번 올릴 수 있는 스킬도 있습니다.
- 이미 찍은 스킬과 이어진 스킬만 찍을 수 있어서, 어느 방향으로 뻗어 나갈지 고르는 재미가 있습니다.
- 바깥쪽 관문은 최고 스테이지가 10, 20, 35, 50에 닿아야 열리고, 그 너머에 강력한 스킬이 있습니다.

| 방향 | 올려 주는 능력 |
|---|---|
| 생존 | 체력, 밀림 저항 |
| 이동 | 가속, 최고 속도 |
| 무기 | 무기 장착과 강화 |
| 골드 | 골드 획득량, 환생 보상 |

## 무기

스킬 트리에서 장착하고 강화합니다.

| 무기 | 특징 |
|---|---|
| 헤머 | 공 주변을 돌며 적을 칩니다. 최대 4개까지 늘어납니다 |
| 전기톱 | 공 앞에서 적을 벱니다 |
| 불도저 | 공 앞에서 적을 밀어냅니다 |
| 드릴 | 공 앞에서 적을 뚫고, 강화하면 공 위쪽에 하나 더 달립니다 |

## 환생

더 올라가기 어려워지면 환생할 수 있습니다.

- 찍은 스킬이 모두 초기화되고 1 스테이지부터 다시 시작합니다.
- 대신 지금까지 도달한 최고 스테이지에 비례해 많은 골드를 받습니다.
- 받은 골드로 스킬을 더 빠르게 다시 찍고, 전보다 높은 스테이지를 노립니다.
